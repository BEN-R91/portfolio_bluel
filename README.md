Portfolio Sophie Bluel

Projet réalisé dans le cadre de ma formation OpenClassrooms – Intégrateur Web.

Application web permettant de gérer le portfolio d’une architecte d’intérieur, avec affichage dynamique des projets et interface d’administration.

Fonctionnalités
Affichage dynamique des projets
Filtrage des réalisations par catégorie
Authentification administrateur
Ajout et suppression de projets
Communication avec une API
Gestion séparée du Front-End et du Back-End
Technologies utilisées
JavaScript
HTML
CSS
API REST
Git / GitHub
Objectif du projet

Mettre en pratique la manipulation du DOM, la gestion d’événements, l’utilisation d’une API et la création d’une interface d’administration dynamique.

Lancement du projet

Le projet contient deux parties :

FrontEnd
Backend

Le backend doit être lancé séparément du frontend en suivant les instructions fournies dans le dossier correspondant.
